Para este trabajo desarrollamos una aplicación de inscripción para el festival ficticio Sonido Sur usando React Native, Expo y React Hook Form.

La aplicación permite completar un formulario con distintos datos, validar cada campo y mostrar los errores cuando algo está mal. Cuando el formulario es correcto, se muestra un ticket con la información ingresada.

Organizamos el proyecto en varios componentes para que el código sea más claro y fácil de entender. Usamos useForm, Controller y rules para manejar los datos y las validaciones del formulario.

También usamos useState para guardar la inscripción y decidir si mostrar el formulario o el ticket. Los datos se pasan entre componentes usando props.

La inteligencia artificial nos ayudó a organizar la estructura del proyecto, crear una primera versión del código y entender mejor cómo funcionaban algunas partes. Después revisamos y adaptamos el código para que fuera más simple y fácil de explicar.

Este trabajo nos ayudó a practicar React Native, componentes, props, estados, formularios, validaciones y renderizado condicional.
